# Аксезім — GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи `index.html` и папку `images`.
3. Открой Settings → Pages.
4. В Source выбери `Deploy from a branch`.
5. Выбери `main` и `/ (root)`.
6. Нажми Save.
7. Через некоторое время GitHub выдаст ссылку на сайт.

Не переименовывай папку `images` и файлы фотографий, если не меняешь пути в HTML.
